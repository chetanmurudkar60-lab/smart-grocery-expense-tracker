# Smart Grocery Expense Tracker

Full-stack React Native grocery and expense tracking application.

## Features

- User Authentication
- Grocery Management
- Expense Tracking
- Dashboard Overview
- MongoDB Integration
- REST APIs using Express.js

## Tech Stack

### Frontend
- React Native
- Expo

### Backend
- Node.js
- Express.js

### Database
- MongoDB

## Installation

### Frontend

```bash
npm install
npx expo start
